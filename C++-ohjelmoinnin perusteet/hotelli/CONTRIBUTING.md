# Osallistuminen projektiin

## Setup

Kloonaa repository:
```bash
git clone https://github.com/Riyadh-Muradi/TAMK25.git
```

Siirry hakemistoon:
```bash
cd "C++-ohjelmoinnin perusteet/hotelli"
```

Asenna riippuvuudet:
```bash
pnpm install
```

Käynnistä sovellus:
```bash
pnpm dev
```

## Koodin rakenne

Frontend:
- `app/` - Next.js sivut
- `components/` - React komponentit
- `lib/` - Apufunktiot
- `styles/` - CSS ja Tailwind

Backend:
- `c++/hotelli.cpp` - Pääohjelma
